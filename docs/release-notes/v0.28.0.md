## What's in it

- **Sharper by default.** Outputs up to 1080p now render at twice their size and are filtered down, which takes out most of the shimmer in fine particle fields. The room's lines are drawn anti-aliased, one output pixel wide, and put the same light into the frame at every render scale. Sprites smaller than a pixel are widened and dimmed rather than left to flicker. A machine that can't hold 2× can set 1× in the output panel.
- **A graded finish.** `grade` in the FX panel meters each frame and eases the exposure, rolls highlights off through AgX instead of clipping them to flat discs, and swaps the glow for a mip-chain bloom. At 0, the default, every frame is exactly what it was. The pictures on [/clouds](https://vizz.letissier.ie/clouds) are now drawn by the same renderer the app uses.
- **Solid surfaces.** `surface` in the particles panel draws the cloud as solid, lit discs instead of glowing sprites: they hide each other, the lamps light the side that faces them, the sun casts the cloud's shadow on the floor, and the room becomes lit walls with a glowing grid. It costs more than glow, so it is a switch, not the default.
- **Switch simulations without stopping.** The `simulate…` menu is now on the live slot while a simulation is running, so picking another one replaces it in one press. `rescan` is no longer offered on a running simulation, where it swapped it for a network listener.

Everything before this is in [v0.27.0](https://github.com/legofsalmon/vizz/releases/tag/v0.27.0). The changelog with pictures is on [vizz.letissier.ie](https://vizz.letissier.ie/#changelog), and where every generator and simulation came from is on [vizz.letissier.ie/clouds](https://vizz.letissier.ie/clouds).
