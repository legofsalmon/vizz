## What's in it

vizz 1.0.0 is the first release sold from [letissier.ie](https://letissier.ie/shop). Every earlier release was numbered 0.x; the numbering starts again here, and the in-app updater on any 0.x build offers 1.0.0.

- **A licence, with a 30-day trial.** Start the trial or enter a key in the panel's `licence` section. A copy with neither sends nothing out — Syphon, NDI or recordings — until one is in. A licence arriving mid-set takes effect at once, and nothing about a licence ever stops a show that is already running. Licences work offline for 30 days between check-ins, and a machine with no internet can be activated from the account page.
- **A crash puts the show back.** If vizz closes unexpectedly, the next launch restores the look that was playing and turns the NDI feed back on. A frame that fails is skipped, and vizz carries on.
- **Crash reports, only if you say so.** After a crash vizz asks once: *Send a crash report to LeTissier Creative Studios?* A report carries the version, the OS and the error's backtrace with your user name taken out — never your shows, presets, sources, licence or email. *Send crash reports automatically* in help & feedback is off unless you turn it on.
- **Send feedback from the app.** `help & feedback` in the panel takes a bug, an idea, a question or praise, with an optional email for a reply. Nothing is posted publicly unless you tick the box that says so. It waits for a network if there is none.
- **Open-source notices in the bundle.** `THIRD_PARTY_NOTICES.md`, inside the app, credits every crate, framework and font vizz is built on.

Everything before this is in [v0.28.0](https://github.com/legofsalmon/vizz/releases/tag/v0.28.0). The changelog with pictures is on [vizz.letissier.ie](https://vizz.letissier.ie/#changelog).
